Vacua vault workflow

Local search results are first written as session data, then designated, validated, and optionally published to the shared HuggingFace vault.

Local vacuum search
FluxVacuaFinder Produces flux vectors, moduli values, masses, and diagnostics.
Search metadata Records model identity, tadpole bound, solver settings, and labels.
DataFrame / parquet Normalised tabular representation of the accepted solutions.
Session tier
VacuaWriter.vacua_writer Writes local run files, supports query/load/delete helpers, and keeps raw search output reproducible.
Designation and review
Designation layer designate_vacua, query_designated, retraction, and purge operations.
vacuavault validation Schema checks, identity checks, optional physics checks, and catalogue rebuilds.
Shared publication target
aschachner/vacua_vault Curated HuggingFace dataset with validated parquet files, rebuilt catalogues, and downstream fetch helpers.
